# 📄 Version HTML de l'Application Formation

## 🎯 Description

Cette version HTML/JS/CSS autonome de l'application **Simulation Rémunération Formation** peut être utilisée directement dans un navigateur web, sans nécessiter Python ou Streamlit.

## 🚀 Utilisation

### Méthode 1 : Double-clic (le plus simple)
1. Localisez le fichier `appFormation.html` sur votre ordinateur
2. Double-cliquez dessus
3. Il s'ouvrira automatiquement dans votre navigateur par défaut

### Méthode 2 : Via le navigateur
1. Ouvrez votre navigateur web (Chrome, Firefox, Edge, Safari, etc.)
2. Appuyez sur `Ctrl+O` (Windows/Linux) ou `Cmd+O` (Mac)
3. Sélectionnez le fichier `appFormation.html`
4. Cliquez sur "Ouvrir"

### Méthode 3 : Glisser-déposer
1. Ouvrez votre navigateur web
2. Glissez le fichier `appFormation.html` dans la fenêtre du navigateur

## ✨ Fonctionnalités

✅ **Toutes les fonctionnalités de l'application Streamlit :**
- 🎯 Simulation de rémunération interactive
- 📘 Informations sur les formations
- 💶 Détails sur les rémunérations
- 🌍 Dispositif SFER (Hauts-de-France)
- 🌓 Mode clair/sombre avec boutons
- 🔒 Section Sécurisation de la Formation
- 📞 Contacts utiles
- 📋 Documents à préparer

## 💾 Sauvegarde des préférences

L'application sauvegarde automatiquement votre préférence de thème (clair/sombre) dans le stockage local de votre navigateur. Elle sera conservée lors de vos prochaines visites.

## 📱 Compatibilité

- ✅ Compatible avec tous les navigateurs modernes
- ✅ Responsive (fonctionne sur mobile, tablette, ordinateur)
- ✅ Fonctionne hors ligne (aucune connexion internet requise)
- ✅ Aucune installation nécessaire

## 🔧 Personnalisation

Si vous souhaitez modifier l'application :
1. Ouvrez `appFormation.html` avec un éditeur de texte
2. Modifiez le contenu HTML, CSS ou JavaScript selon vos besoins
3. Enregistrez et rechargez dans le navigateur

## 📝 Notes importantes

- Cette version est **100% autonome** et ne nécessite aucun serveur
- Toutes les données restent **locales** sur votre machine
- Aucune information n'est envoyée à des serveurs externes
- Vous pouvez utiliser cette application même sans connexion internet
